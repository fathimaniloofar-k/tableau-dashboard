# 📊 Marketing & Product Performance Analysis Using Tableau

## 📌 Project Overview

This project focuses on analyzing marketing campaigns and product performance using Tableau. The main objective is to understand how marketing budgets, discounts, subscription tiers, and keywords influence revenue generation, sales, and customer satisfaction.

An interactive Tableau dashboard was created to visualize important business metrics and identify patterns that can help businesses make better marketing decisions.

## 🎯 Project Objectives

- Analyze overall revenue and product sales.
- Evaluate marketing campaign performance using ROI.
- Understand revenue contribution from different subscription tiers.
- Analyze the relationship between marketing budget and revenue.
- Study the impact of discounts on units sold.
- Identify keywords that generate higher revenue.
- Understand customer satisfaction after refunds.

## 📂 Dataset Information

**Dataset Name:** Marketing and Product Performance

**File Format:** CSV

**Number of Records:** 10,000

**Number of Columns:** 17

### Important Features

| Column | Description |
|---|---|
| Campaign_ID | Unique marketing campaign identifier |
| Product_ID | Unique product identifier |
| Budget | Marketing campaign budget |
| Clicks | Number of clicks |
| Conversions | Number of successful conversions |
| Revenue_Generated | Revenue generated |
| ROI | Return on Investment |
| Subscription_Tier | Customer subscription category |
| Subscription_Length | Subscription duration |
| Discount_Level | Discount offered |
| Units_Sold | Number of units sold |
| Bundle_Price | Price of product bundles |
| Customer_Satisfaction_Post_Refund | Customer satisfaction score |
| Common_Keywords | Keywords associated with marketing |
