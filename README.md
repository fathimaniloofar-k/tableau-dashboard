# Marketing and Product Performance Analysis using Tableau

## Project Overview
This project focuses on analyzing marketing campaigns and product performance using Tableau. The main objective is to understand revenue generation, marketing efficiency, sales performance, customer satisfaction, and the impact of discounts.

An interactive Tableau dashboard is developed to visualize important business metrics and help identify patterns and trends in marketing and product performance.

## Dataset Description
The dataset contains 10,000 records and 17 columns related to marketing campaigns, products, customers, sales, and subscriptions.

### Key Features
- **Budget:** Marketing campaign budget.
- **Clicks:** Number of clicks received.
- **Conversions:** Number of successful conversions.
- **Revenue_Generated:** Revenue generated from campaigns.
- **ROI:** Return on Investment.
- **Subscription_Tier:** Customer subscription category.
- **Discount_Level:** Discount offered.
- **Units_Sold:** Number of products sold.
- **Bundle_Price:** Price of product bundles.
- **Customer_Satisfaction_Post_Refund:** Customer satisfaction rating.
- **Common_Keywords:** Keywords associated with marketing campaigns.

## Tools Used
- Tableau Public
- Microsoft Excel / CSV
- GitHub

## Project Objectives
1. Analyze total revenue and sales performance.
2. Identify the best-performing subscription tiers.
3. Understand the relationship between marketing budget and revenue.
4. Analyze the impact of discounts on units sold.
5. Evaluate customer satisfaction after refunds.
6. Identify high-performing marketing keywords.
7. Analyze the distribution of Return on Investment (ROI).

## Dashboard Features
The interactive dashboard includes:

- Total Revenue KPI
- Total Conversions KPI
- Total Units Sold KPI
- Average ROI KPI
- Revenue by Subscription Tier
- Marketing Budget vs Revenue
- Discount Impact on Sales
- Customer Satisfaction Analysis
- Keyword Performance
- ROI Distribution

## Filters and Interactivity
The dashboard includes interactive filters for:
- Subscription Tier
- Common Keywords
- Discount Level

These filters allow users to explore the data based on different categories.

## Key Insights
The project aims to identify:
- Which subscription tier generates the highest revenue.
- How marketing budgets relate to revenue generation.
- Which discount levels are associated with higher sales.
- Which keywords perform better.
- How customer satisfaction varies after refunds.

## Conclusion
This project demonstrates how Tableau can be used to transform raw marketing data into meaningful visualizations and interactive dashboards. It helps in understanding business performance and supports data-driven decision-making.
